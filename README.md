# TEAM 810 SCIENCE V2 — نسخهٔ امن

## تنظیم متغیرهای محیطی
پیش از Deploy، این متغیرها را در پنل هاست تنظیم کنید؛ آن‌ها را داخل `app.py` یا مخزن عمومی ننویسید:
- `OPENAI_API_KEY`: کلید OpenAI API
- `ADMIN_PASSWORD`: یک رمز طولانی و خصوصی برای صفحه آمار مدیر
- `TELEGRAM_BOT_TOKEN`: توکن رباتی که از BotFather گرفته‌اید
- `TELEGRAM_ADMIN_CHAT_ID`: شناسه چت تلگرام مدیر
- `OPENAI_MODEL`: نام مدل در دسترس حساب شما

کلیدها و رمزهای واقعی را در چت، اسکرین‌شات یا مخزن عمومی منتشر نکنید. برای پروژه عمومی، Environment Variables امن‌تر است.

## Render
Build command: `pip install -r requirements.txt`
Start command: `gunicorn app:app`

## گزارش خصوصی
مسیر `/owner-stats` با رمز `ADMIN_PASSWORD` محافظت می‌شود. برای مشاهده، از درخواست دارای هدر `X-Admin-Password` استفاده کنید. از قرار دادن رمز در URL یا ارسال آن به دیگران خودداری کنید.

## آفلاین
پس از بازکردن سایت آنلاین، مرورگر سازگار می‌تواند صفحه اصلی را کش کند. ماشین‌حساب، قلم دیجیتال و ابزارهای محلی می‌توانند آفلاین کار کنند؛ پاسخ هوش مصنوعی، گزارش تلگرام، آمار سرور و تبلیغات آنلاین به اینترنت نیاز دارند.

## اعلان‌ها و درآمد
در فایل فقط جایگاه اعلان وجود دارد؛ درآمد واقعی فعال نمی‌شود تا شبکه تبلیغاتی شما سایت را تأیید کند و کد تبلیغاتی رسمی اضافه شود.
